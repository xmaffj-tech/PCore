PCore — приложение для Windows, которое помогает следить за состоянием компьютера, оборудованием и системными показателями.

Скачать для Windows Открыть GitHub
Windows 10 · 64-bit · Требуется .NET Framework 4.8

Возможности PCore

Мониторинг системы

Просмотр загрузки процессора, оперативной памяти и накопителей.

Датчики оборудования

Отображение доступных температур, частот и других показателей поддерживаемых устройств.

История и статистика

Сохранение системных показателей и просмотр изменений во времени.

Как установить

1
Скачай установщикНажми «Скачать для Windows» и дождись загрузки PCore-Setup-x64.exe.
2
Запусти файлОткрой скачанный установщик. Если Windows покажет запрос контроля учётных записей, подтверди запуск, если доверяешь файлу.
3
Заверши установкуСледуй инструкциям мастера установки и запусти PCore.
